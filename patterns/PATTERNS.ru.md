# Паттерны Реализации DOF-Core

Этот документ описывает техническую реализацию фреймворка DOF-Core для интеграции в AI-системы, автономных роботов и LLM-оркестраторов. Цель — отделить генеративное творчество от строгой математической валидации.

---

## 🇷🇺 Русский: Паттерны Реализации

### Паттерн 1: Трехслойная Изолированная Архитектура
Система разделяется на три изолированных контура с однонаправленным потоком данных, что исключает влияние галлюцинаций LLM на физические действия.

1. **Слой Восприятия и Картографирования (Graph Mapper):**
   - **Задача:** Опрашивает среду и строит `StateGraph`. Переводит физические объекты в структуры `Entity` с числовым вектором DoF. Вычисляет глобальный $\tau$ (Time-to-Collapse). Читает **средства действующего агента по ресурсам**, выведенные группы обмена и наблюдаемые курсы (§3.2, §4.8) — блочные числа линзы Options **выводятся** из требований, этих средств и групп, а не авторствуются вручную (§4.6).
2. **Слой Синтеза (The Generator):**
   - **Задача:** Получает карту графа. Генерирует массив гипотетических стратегий (3–5 различных путей). Ему запрещено напрямую управлять приводами.
3. **Слой Валидации (Calculus Core):**
   - **Задача:** Принимает планы от Генератора. Проводит симуляцию для каждого. Фильтрует их через нелинейную формулу $\sum \ln(\text{DoF})$. Путь, приводящий *счётную* сущность к известному нулю, несёт **плату за коллапс** и **изымается из набора кандидатов**, пока существует безвредная альтернатива (структурная допустимость, `DOF-SPEC` §4.2/§4.5); в аудите коллапс виден как конечный пол $\ln \varepsilon$, а не как число, которое выигрыш в другом месте мог бы выкупить. Путь, за который агент **не может заплатить**, изымается так же: прямое сравнение со средствами агента, затем *проверенная* конверсия внутри группы обмена по наблюдаемому курсу (собственное время обмена списывается в тот же $\tau$), и если нехватка это переживает, опция несёт `gate = "insolvency"` (§4.8): недоступное по средствам — вердикт, а не цена.

### Паттерн 2: Реактивный контур с прерыванием
Предотвращает «аналитический паралич», связывая вычислительные такты с физическим временем до катастрофы ($\tau$).

- **Если $\tau \ge 5000000.0$ µs (5 секунд):** **Глубокая Диверсификация**. Запуск LLM-слоя для поиска скрытых альтернатив.
- **Если $\tau < 5000000.0$ µs (5 секунд):** **Быстрый Проход (Fast Pass)**. Генератор отключается. Система переходит на жестко прописанные детерминированные сценарии (Minimax Bounds).

### Паттерн 3: Программный фильтр опциональности (Calculus Evaluator Pipe)
Детерминированная реализация (Python/Rust/C++) ядра оценки.
- **Логика:** Расчет совокупного DoF системы.
- **Выбор:** $\text{Net Delta} = \text{Total System DoF Evaluation Index}_{\text{projected}} - \text{Total System DoF Evaluation Index}_{\text{current}} - \Delta T$.
- **Ограничение:** Необратимые действия получают структурный штраф (например, $-0.5$).
- **Ресурсные ворота:** каждая опция объявляет, что она берёт у действующего агента (§3.3; минус — расход, `energy` пишется явно, даже `0.0`). Опция **изымается, а не штрафуется**, если расход превышает объявленные средства даже после полной проверенной конверсии (`gate = "insolvency"`, §4.8), и каждое изъятие попадает в `removed_options`.
- **Базовая линия:** ничего не делать — эталон: без $\Delta T$, значит $\text{Net Delta} = 0$ по определению. Опция выбирается только при **строго положительном** $\text{Net Delta}$; иначе система остаётся на месте, и это записано в аудите.

### Референсная Реализация (Файлы с кодом)
Каталог `patterns/` содержит исполняемый Python-SDK, реализующий все слои:
- `patterns/python/graph_mapper.py` — Слой Восприятия и Картографирования (строит `SystemStateMatrix`, вычисляет τ).
- `patterns/python/generator.py` — Слой Синтеза (генерация вариантов на базе LLM с детерминированным fallback).
- `patterns/python/calculus_core.py` — Слой Валидации (логарифмическая сумма DoF, выбор с учётом ΔT).
- `patterns/python/orchestrator.py` — Реактивный контур с прерыванием (связывает слои; FAST PASS / DEEP DIVERSIFICATION).
- `patterns/python/smoke_test.py` — Минимальный запускаемый пример.
- **Порты на другие языки** (та же логика, проверены на запуск):
  - `patterns/rust/` — порт на Rust (`dof_core.rs`, `graph_mapper.rs`, `generator.rs`, `orchestrator.rs`, `main.rs`).
  - `patterns/go/` — порт на Go (`dof_core.go`, `graph_mapper.go`, `generator.go`, `orchestrator.go`, `main.go`, `go.mod`).
  - `patterns/cpp/` — порт на C++ (`dof_core.hpp`, `graph_mapper.hpp`, `generator.hpp`, `orchestrator.hpp`, `main.cpp`).
- `patterns/tools/verify_ports.sh` — прогоняет все четыре порта против одного замороженного дайджеста и печатает число проверок каждого; доказательство конформности §7 одной командой.
